# 拼字帖 · Calligraphy to Copybook

当前版本：**0.1.0**

## 这是什么

拼字帖是一款离线书法字帖生成器。它把网上收集、拍照或截图得到的书法单字图片，自动整理成尺寸统一、可直接打印的 A4 田字格、米字格或方格字帖，并支持原字参考、浅灰描红和空白练习纸三种输出。

整个程序只有一个 `index.html`，图片识别、图库管理、排版和打印都在本机浏览器中完成，不会上传图片，也不需要服务器或网络连接。

## 运行平台

- **macOS**：推荐 Safari、Chrome 或 Edge；
- **Windows**：推荐 Chrome 或 Edge；
- **Linux**：推荐 Chrome、Chromium 或 Edge；
- 直接双击 `index.html` 即可运行，无需安装。桌面浏览器最适合排版和 A4 打印；手机浏览器可查看，但不建议承担正式打印工作。

## 使用步骤

1. **打开程序**  
   双击项目根目录的 `index.html`。页面右上角可随时打开「使用说明」和「更新日志」，不占用左侧设置与图库空间。

2. **导入单字图片**  
   在左侧「图库」右上角点击醒目的「＋ 导入图片」，可一次选择多张 PNG、JPG、JPEG 或 WebP。也可以把图片拖进页面，或按 `Ctrl+V`（macOS 为 `Cmd+V`）粘贴截图。HEIC 请先转换成 PNG/JPG。

3. **整理图库和字帖**  
   图库按日期保存导入内容。点选图片后可批量加入字帖、移出或删除；双击单个图片可直接加入。可按日期筛选，或只看没用过的字。字帖用字支持拖动排序、批量移除和逐字缩放；点击「自适应」可恢复统一尺寸。

4. **配置排版**  
   在「字帖设置」中选择每行/每列数量、每字重复次数、标题、排列方式、田字格/米字格/方格，以及当前预览模式：

   - **原图效果**：深色原字，适合作为字样参考；
   - **临摹描红**：浅灰字，适合覆纸或直接描摹；
   - **空白格**：只打印练习格。

   「逐字连排」会从左到右连续排列；「每字一行」会让一个字占一整行，临摹模式下每行第一格保留深色例字。

5. **打印当前字帖**  
   在「A4 预览」一行最右侧点击「打印当前字帖」。打印内容始终与当前预览和排版配置一致，不会在点击打印时切换原图或描红模式。系统打印对话框中选择 **A4、纵向、缩放 100%**。

## 图像处理与排版能力

- 整张原图参与识别，再按完整笔画边界等比缩放并居中；字太大只会缩小，不会为了卡尺寸裁断笔画；
- 自动区分纸底与墨迹，去除拍照高光、阴影、纸纹、外框和田/米字格辅助线；
- 支持白底黑字、黑底白字，以及白底/灰底红、绿、蓝等单色字迹；
- 保留淡墨、飞白、细锋和独立点画，并抑制纸纹噪点、孔洞和锯齿；
- 字形始终位于格线图层上方，虚线不会视觉截断笔画；
- 所有字按完整外接框统一大小，同时允许单字 60%–110% 微调；
- 自动分页，支持逐字连排、每字一行、每字重复和最多 60 页实时预览，打印时输出全部页面。

## 数据与隐私

- 导入图片保存在当前浏览器的 IndexedDB 中，排版设置和字帖顺序保存在本机；
- 程序不联网、不上传图片；
- `file://.../index.html` 与 `http://localhost/...` 属于不同浏览器存储域，二者的图库不会自动合并；
- 清除浏览器网站数据会删除图库，请自行保留原始图片。

## 开发与验证

- 正式应用入口：`index.html`；
- 核心是原生 HTML、CSS 和 JavaScript，无运行时依赖；
- 浏览器回归脚本位于 `tests/`，主要使用 Playwright；
- 运行测试前执行 `python3 -m pip install -r requirements-dev.txt` 和 `playwright install chromium`；
- 当前内嵌字形处理版本为 v17，应用发布版本为 0.1.0。
